## 修复后回归

- 数据库时间精度差异导致相同提醒重试误判：输入统一到毫秒。
- 数据库 MySQL utf8mb4 下 varchar(20000) 不合法：正文改为 MEDIUMTEXT，任务描述为 TEXT，加入 20,000 字中文测试。
- 颜色按钮默认提交表单：改为 type=button。
- 手机端折叠导航丢失可访问名称：增加 aria-label。
- MySQL Windows 启动对中文路径及 PowerShell 参数处理异常：使用同目录 NTFS 短路径与显式长参数。
