拾记 v0.3.8 · 新版龙娘桌宠

完整解压 shiji-0.3.8-windows-x64.zip 后双击 Start.cmd。普通使用者请选择此便携 ZIP，源码 Source code ZIP 需要自行构建。

- 换用新版白发紫瞳龙娘透明皮肤，预生成多尺寸高质量缩图，改善小尺寸显示；没有 AI 重绘或新增运行依赖。
- 默认桌宠由 120 增至 144 个逻辑像素，宽高增加 20%；可选 72/96/120/144/160 五档。旧标准 120 首次升级为 144，之后手动选择的大小会保留。
- 添加柔和光影与落地阴影，随呼吸和点击弹跳同步变化；气泡随窗口居中，保留白紫四项右键菜单、备忘录、任务和本机定时提醒。
- 本机通过 25 项隔离便携检查、8 项原生 API、8 项 UI；尺寸升级和最终布局已验证。GitHub 发布包由独立 Windows runner 重新构建并测试。另一台全新 Windows 电脑、跨屏 DPI 与本版通知横幅收件仍需人工验收。
- 支持 Windows 10/11 x64、.NET Framework 4.8，自带 Java 21，无需安装 MySQL、Node.js、Maven 或 Codex。

升级：先运行旧版 Stop.cmd，备份完整 .local 文件夹；解压新版到新目录后，将旧版 .local 复制过去再运行 Start.cmd。不要同时启动使用同一份数据的副本。
