Windows 小桌宠版：下载 `shiji-版本-windows-x64.zip`，完整解压后双击 `Start.cmd`。

- 新增原生透明小猫桌宠，默认 96 逻辑像素，可拖动，可选 72/96/120 三档，支持托盘收起和恢复。
- 点击桌宠直接添加一次性提醒、备忘录和任务；查看/取消提醒、编辑备忘录和完成任务。
- 提醒添加返回完整计划时间，取消立即关闭后续通知；重试同一提醒不会重复创建。
- 保留原网页，通过 `OpenBrowser.cmd` 或桌宠菜单打开。
- 自带 Java 21，无需 Java、Node、Maven、MySQL 或 Codex；桌宠需要 Windows .NET Framework 4.8，`Check.cmd` 检查，不自动下载系统组件。

升级前运行旧版 `Stop.cmd`，备份旧目录，再将完整 `.local` 复制到新解压目录。默认 H2 与可选 MySQL 数据保持独立。不要公开个人数据和访问密钥。

提醒需要电脑开机、唤醒、保持登录及后台运行；Windows 允许通知。收起到托盘或关闭快捷面板不停止提醒；“退出拾记（停止提醒）”会停止后台。不推送手机。

Windows 自动构建和隔离安装测试不替代另一台全新电脑的人工通知、显示缩放与多显示器测试。
