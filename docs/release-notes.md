龙娘轻动作版 v0.3.3：完整解压便携 ZIP 后，双击 Start.cmd。

- 添加整个角色的呼吸起伏、悬停轻倾和点击弹跳；拖动、打开菜单或隐藏时暂停。托盘“启用轻动作”可开关并保存，遵循 Windows 客户区动画设置。
- 新安装默认 120 逻辑像素；托盘提供 72/96/120/160 四档，旧版大小设置保留。160 像素档自动扩展透明窗口，避免裁剪。
- 透明原图轻微锐化，保持原图尺寸和透明通道；没有生成额外细节。独立眨眼、挥手需要后续帧图或分层素材。
- 保留白紫色四项右键菜单、提醒创建和立即取消、备忘录、任务表及完整网页。
- 本机最终 ZIP 通过 25 项便携检查、原生 API 8 项及原生 UI 8 项；检查动画数值采样和 160 像素渲染图。尚未在另一台全新电脑验收。
- 运行要求：Windows 10/11 x64、.NET Framework 4.8。自带 Java 21；通知需电脑开机、唤醒并保持登录。
- 升级：先运行旧目录 Stop.cmd，将整个 .local 复制到新目录后启动；勿覆盖正在运行的数据库。
