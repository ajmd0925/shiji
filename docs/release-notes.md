拾记 GPT-Pet v0.3.11 · 眨眼与挥手动画

完整解压 shiji-0.3.11-windows-x64.zip 后双击 Start.cmd。普通使用者请选择此便携 ZIP；Source code ZIP 为源码，需要自行构建。

- 项目展示名称更新为“拾记 · GPT-Pet”，同步网页标题、桌宠窗口、托盘标题及 Codex 插件展示名。仓库改为 ajmd0925/shiji-gpt-pet，增加 gpt、pet、gpt-pet 搜索标签。

- 使用原龙娘形象，增加待机眨眼与点击挥手；固定身体和脸部主体，只对眼睛和手臂做局部补间，减少换帧跳动。

- 81 帧预加载透明图集，动作按 30 fps 和实际经过时间播放；挥手约 2.13 秒，完成后回到待机。

- 空闲时每隔 3.8–5.6 秒眨眼；隐藏、拖动、打开菜单及关闭轻动作时暂停。继续遵循 Windows 客户区动画偏好。

- 灯光遮罩和轮廓投影随当前帧同步，保留白紫菜单、五档大小、提醒、备忘录及原页面布局。

- 维护者可使用 prepare-motion.py 从随仓库提供的透明姿势重建图集。普通使用者无需下载素材、Python 或图像处理依赖。

- 已通过本机 10 项桌宠 UI 检查，覆盖动画推进与回到待机、重复点击、停止与恢复、菜单入口和五档大小。本机另通过 25 项便携包检查、8 项原生 API 检查及打包网页连接验证；后端 27 项测试中 26 项通过、1 项跳过。修正云端 Windows 关闭系统动画时的测试分支：独立验证播放器，同时验证实际桌宠遵循系统偏好。GitHub Windows 发布流程会重新构建并复测。

- 支持 Windows 10/11 x64、.NET Framework 4.8，自带 Java 21，无需安装 MySQL、Node.js、Maven 或 Codex。另一台全新电脑仍需实际安装验证。

升级：先运行旧版 Stop.cmd，备份完整 .local 文件夹；将新版解压到新目录，再将旧版 .local 复制过去后运行 Start.cmd。不要同时启动使用同一份数据的副本。若升级后不动，请在托盘打开“轻动作”；该设置保留旧版选择。

动画基于用户提供的素材做局部补间，尚不具备完整走路或转身动作。GPT-Pet 是项目名称，本机提醒与桌宠运行不依赖 GPT API，也不是 OpenAI 官方产品。
