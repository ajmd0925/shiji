拾记 v0.3.9 · 圆角托盘菜单与专属图标

完整解压 shiji-0.3.9-windows-x64.zip 后双击 Start.cmd。普通使用者请选择此便携 ZIP，Source code ZIP 为源码，需要自行构建。

- 托盘菜单采用白紫圆角风格，单击或右键托盘头像即可打开。
- 大小改为 72/96/120/144/160 五档按钮，当前档位高亮；选择后立即生效并自动收起菜单，重复选择当前大小也会关闭。
- 独立提供“显示桌宠”“隐藏桌宠（提醒继续）”和“退出拾记（停止提醒）”；隐藏同时收起操作窗口，退出保留确认提示。
- 使用多尺寸龙娘头像作为托盘及应用图标，替换原蓝色信息图标。
- 保留原有皮肤、动作、网页、提醒与数据，默认大小为 144 逻辑像素。
- 本机通过 25 项隔离便携检查、8 项原生 API 和 9 项 UI 检查；菜单关闭修复后重新通过 9 项 UI 检查。发布包由 GitHub Windows runner 重新构建并测试，另一台全新电脑仍需实际安装验证。
- 支持 Windows 10/11 x64、.NET Framework 4.8，自带 Java 21，无需安装 MySQL、Node.js、Maven 或 Codex。

升级：先运行旧版 Stop.cmd，备份完整 .local 文件夹；将新版解压到新目录，再将旧版 .local 复制过去后运行 Start.cmd。不要同时启动使用同一份数据的副本。
