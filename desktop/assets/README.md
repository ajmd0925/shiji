# 桌宠皮肤素材

`dragon-girl.png` 来自项目使用者本次提供的 JPG 角色图，经过裁剪留白、移除外部白色背景和导出透明 PNG 处理。角色图嵌入桌宠可执行文件，运行时无需额外图片目录或图像处理依赖。

角色使用单张透明图片，通过 WPF 实现整幅图片的轻动作。右键菜单和拖动保持可用，提供 72/96/120/160 逻辑像素大小选项。独立眨眼或肢体动作需要另外制作相应帧或分层素材。

仓库 MIT 代码许可证不替原始图片声明第三方素材权利；素材的使用和分发范围以原始来源许可为准。


v0.3.3 使用透明原图轻微锐化，默认 120 逻辑像素，提供 160 像素大图选项，旧大小偏好继续保留。增加整个角色的呼吸起伏、悬停轻倾及点击弹跳；托盘“启用轻动作”可关闭，遵循 Windows 客户区动画设置，隐藏/拖动/打开菜单暂停。尚无独立眨眼或肢体动画，需要另行制作帧图。
