# 桌宠皮肤素材

当前构建使用 `dragon-girl-motion.png` 动画图集，静态备用图为 `dragon-girl-v3.png`；旧版 `dragon-girl.png` 与 `dragon-girl-v2.png` 保留供回溯。素材均来自项目使用者提供的 JPG 角色图，经过裁剪留白、移除外部白色背景和导出透明 PNG 处理。角色图嵌入桌宠可执行文件，运行时无需额外图片目录或图像处理依赖。

角色支持待机眨眼、呼吸和点击挥手。右键菜单和拖动保持可用，提供 72/96/120/144/160 逻辑像素大小选项。

仓库 MIT 代码许可证不替原始图片声明第三方素材权利；素材的使用和分发范围以原始来源许可为准。


v0.3.3 使用透明原图轻微锐化，默认 120 逻辑像素，提供 160 像素大图选项，旧大小偏好继续保留。增加整个角色的呼吸起伏、悬停轻倾及点击弹跳；托盘“启用轻动作”可关闭，遵循 Windows 客户区动画设置，隐藏/拖动/打开菜单暂停。尚无独立眨眼或肢体动画，需要另行制作帧图。


v0.3.4 保留原 PNG，运行时通过 WPF 图片透明遮罩叠加柔光和淡紫暗部，添加低强度轮廓投影及随呼吸/弹跳变化的落地阴影。未重绘角色，未增加素材或图像处理依赖。


v0.3.5 使用用户新提供的角色 JPG，裁剪主体、提取与边界相连的浅色背景后导出 768×768 透明 PNG：dragon-girl-v2.png。保留原图明暗，没有 AI 重绘；构建资源改用 v2，旧图保留供回溯。继承 v0.3.4 的光影和轻动作。


v0.3.6 新增 dragon-girl-crisp-atlas.png，多尺寸 Lanczos 缩图和轻度亮度锐化，alpha 不变；按 DPI 选择并缓存，无新增运行依赖。原图和造型保留，不声称恢复不存在的细节。


v0.3.7 改用用户第三张 JPG，裁出约 881×960 主体，清除边界连通棋盘格、呆毛及尾巴环内背景和孤立压缩杂点，导出 768×768 RGBA。重新生成多尺寸清晰图集；维护脚本使用相对路径，无运行依赖或 AI 重绘。


v0.3.8 默认尺寸由 120 改为 144 逻辑像素，保留旧档并提供五档大小；气泡居中，多尺寸图集已包含 144 及常见 DPI 所需像素大小。


v0.3.9 shiji.ico 从第三版龙娘透明皮肤的头部裁切，叠加浅紫圆角底，包含 16/20/24/32/48/64/128/256 多尺寸。嵌入托盘及 EXE，prepare-icon.py 可选维护脚本需要 Pillow，普通构建与运行不需要。


本地动画预览版：采用用户提供的眨眼与挥手姿势（animation-source），固定统一主体，仅眼睛与左手区域做补间。prepare-motion.py 使用 Pillow / NumPy 在维护阶段生成 81 个 320×320 帧及布局 JSON；普通构建与运行无需 Python。以 30 fps 按真实经过时间选帧，资源预载并冻结，安静等待 3.8–5.6 秒后眨眼，点击播放约 2.13 秒挥手后回到待机。隐藏、拖动、打开菜单、关闭轻动作或系统关闭客户区动画时停止帧定时器。光照遮罩和轮廓投影与当前帧同步。这是现有素材的局部补间，不是新绘制的完整角色动画，也未提供全部九种 Hatch Pet 动作。

维护者可执行 `python desktop/prepare-motion.py`，加 `--preview <目录>` 输出双色动画预览与接触表。输入是去底并统一视口后的源姿势，路径均相对项目目录。用户安装不需要素材处理依赖。
